# اجزا و کتابخانه‌های ممنوع و دارای محدودیت (Restricted Components)

جهت تضمین مالکیت فکری، امنیت حقوقی و استقلال پلتفرم کاردو ERP، ورود موارد زیر به هسته پروژه اکیداً ممنوع یا منوط به شروط سخت‌گیرانه است:

## ۱. کدهای تحت لایسنس AGPL-3.0 یا GPL-3.0
- **وضعیت:** ممنوعیت کپی مستقیم در مخزن کاردو (`main-eca`).
- **دلیل:** لایسنس‌های کپی‌لفت قوی الزام به افشای کل سورس کد سیستم پیوندیافته ایجاد می‌کنند.
- **راهکار جایگزین:** استفاده به عنوان سرویس مستقل (Sidecar Microservice) پشت API ایزوله یا پیاده‌سازی مجدد منطق با کد تمیز TypeScript بومی.

## ۲. استفاده از سرویس‌های آنلاین وابسته به تحریم یا قفل‌شونده
- پلتفرم‌های ابری خارجی که دسترسی کاربران ایرانی را قطع می‌کنند یا نیازمند اشتراک دلاری مسدودشونده هستند ممنوع هستند.
- تمامی ابزارهای پشتیبان‌گیری، پایگاه داده، احراز هویت و ذخیره‌سازی باید قابلیت اجرای ۱۰۰٪ آفلاین (Self-hosted on-premise) روی سرور لینوکس یا ویندوز محلی را داشته باشند.
