# ADR-003: استقرار دیزاین سیستم متراکم سازمانی (KARDO Design System) و پوسته یکپارچه RTL

- **وضعیت:** پذیرفته‌شده (Accepted)
- **تاریخ:** ۸ نوامبر ۲۰۲۶
- **تصمیم‌گیرندگان:** لید UI/UX، معمار فرانت‌اند

---

## ۱. زمینه و صورت مسئله (Context)
صفحات فعلی وب کاردو با وجود کارآمدی، از الگوهای بصری متنوعی در هدر، سایدبار، جداول و دیالوگ‌ها استفاده می‌کردند. این حالت حس یک نرم‌افزار سازمانی یکپارچه با استانداردهای رده‌بالای بین‌المللی (مانند مایکروسافت داینامیکس یا اودوو) را به کاربر نمی‌دهد. همچنین کار با داده‌های انبوه نیازمند تراکم اطلاعاتی (Information Density) و تجربه بومی و بی‌نقص فارسی/راست‌چین است.

## ۲. تصمیم (Decision)
1. ایجاد توکن‌های متمرکز دیزاین در Tailwind CSS v4 شامل مقیاس رنگ‌های سازمانی (سرمه‌ای تیره شرکتی، طوسی سرد، فیروزه‌ای تاکیدی)، فونت فارسی استاندارد (Vazirmatn / Shabnam)، و سیستم فاصله‌گذاری متراکم (Compact Spacing).
2. ساخت پوسته اصلی سازمانی (Application Shell) شامل:
   - سایدبار ماژولار تاشو با آیکون‌های استاندارد و دسته‌بندی دامنه‌ها.
   - نوار وضعیت و ابزار بالا شامل جستجوی هوشمند سراسری (Command Palette / `Ctrl+K`).
   - تعویض‌کننده شعبه/انبار و مشخصات حساب کاربری.
   - نوار مسیر (Breadcrumbs) و دکمه‌های اقدام متنی (Contextual Actions).
3. توسعه الگوی واحد جدول داده‌ها (Data Table) مبتنی بر TanStack Table با امکانات فیلتر ستونی، سورت، جابجایی ستون‌ها و خروجی اکسل با فرمت UTF-8 BOM.

## ۳. پیامدها (Consequences)
- سرعت بالا در اجرای وظایف روزمره حسابداران و مدیران بدون نیاز به اسکرول‌های طولانی.
- یکدستی کامل تمام ۳۸ صفحه کنونی و ماژول‌های جدید آینده.
